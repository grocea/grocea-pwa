## Implementation plan

Provide searchable ingredient multi-selection with Add/Set amounts, per-row units and optional whole pack count times pack size. Reuse exact bigint/Decimal conversion; preview before/change/after and a final save count. Validate duplicates, range, family and precision before committing. Save as one atomic idempotent revisioned mutation and one traceable multi-change activity event. Keep draft values after validation errors. Make zero-stock/empty Pantry point to setup; preserve existing single-item adjustment.

## Acceptance criteria

At least three ingredients can be added/set at once; 2 packs of 0.5 kg produces exactly 1000 g; invalid row prevents all writes; row deletion/editing accessible by keyboard; offline save/reload/reconnect retains all rows and one event; duplicate replay adds nothing twice; stale Set operations conflict explicitly.
