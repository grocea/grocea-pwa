## Implementation plan

Add nullable canonical threshold and refill quantity per account pantry stock. Null threshold preserves existing depleted semantics. Trigger at balance <= configured threshold; zero remains valid, negatives invalid. Preferred refill is a fixed purchase amount, not target stock. Provide accessible per-item settings; disabling threshold restores depleted-only. Sync as idempotent revisioned mutation; retain on stock changes and clear deliberately on untrack; normalize old IndexedDB/import state. Prefill restock form while allowing review.

## Acceptance criteria

Legacy users retain depleted-only behavior; setting 500 g flags 500 g and below but not 501 g; no untracked ingredient is flagged; quantity family/range validation works; preferences survive reload/offline/reconnect/another device; stock mutation retains preferences; restock prefill uses exact selected amount.
