## Implementation plan

Implement SMTP reset request and confirm with cryptographically random hashed single-use expiring tokens, shared-store throttling, generic responses and no token logging. Use trusted configured public origin and TLS outside local. Reset invalidates sessions/tokens and requires normal login. Add authenticated versioned JSON export excluding auth secrets, with honest pending-change handling. Add online current-password account deletion with explicit confirmation, dependency-safe owned-data deletion and local IndexedDB/outbox/auth/trial cleanup. Preserve global records and other accounts. Handle in-flight sync/cross-tab invalidation. Document SMTP settings and local verification.

## Acceptance criteria

Known/unknown email requests give same public shape; local SMTP receives real reset mail; valid token resets once; expired/replayed token fails; old password and old sessions fail; export contains owned kitchen data and no secrets; wrong password blocks deletion; correct deletion removes only disposable account and invalidates all sessions/caches.
