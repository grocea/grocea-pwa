## Implementation plan

Prepare a 3–5 participant one-week protocol with setup/shop/cook/return tasks and interview prompts. Add opt-in on-device trial journal with clear collected fields, start/stop/reset/export controls, no automatic network transmission, no pantry/recipe contents or credentials. Record only coarse successful workflow milestones and dated self-reported friction notes, scoped to account, robust to offline and failures. Export JSON for participant-controlled sharing. Capture first pantry setup, shopping completion, cooking and return on a later day. Retain consent/version metadata and delete on account removal.

## Acceptance criteria

Off by default; no data recorded before consent or after stopping; local entries survive reload/offline but cannot cross accounts; only successful durable actions record milestones; export is readable, excludes auth secrets and pantry contents; participant can clear all trial data; protocol includes outcome definitions and no invented results.
